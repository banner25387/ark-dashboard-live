ケツァルコアトルス／高空飛行生物用トラップ（プラットフォーム檻・チェインボーラ・冷凍落下の 3 方式）

繁体中文版：quetzal-trap.md｜データ表：data/陷阱表.csv 本文は出典をもとに書き起こしたもので、原文の転載ではありません。節ごとに出典を明記。 出典に無い事は「未確認」と書き、推測では埋めません。

野生のケツァルコアトルスは決して着地しないため、地上のトラップでは捕らえられない。 そこでトラップを空に持っていくか、先に地上へ落とすかの二択になる。出典が示す実用的な方法は 3 つ： A プラットフォーム檻（1 体目を入手済みなら最も楽）、B チェインボーラで地上に落とす、 C 雪フクロウの冷凍で落としてから恐竜用ゲートの枠で囲う。

2. サイズ

  • A 方式：出典は「ドア枠で 3×3×3 の箱」と書く一方、同じ段落でプラットフォームサドルでは完全な立方体にできないとも述べる。 実際の判定基準は開口部の規格：「幅が 1 マスより広く、かつ高さも 1 マスより高い」穴を作らないこと。 出典の例——「高さ 3 マス・幅 1 マス」の穴なら野生個体は閉じ込められる。「2×2」の穴は抜けられる可能性がある。
  • B 方式：固定サイズ無し（弾道で命中させる）。チェインボーラの拘束時間は約 15 秒。
  • C 方式：ゲートの枠を三角形に配置し、本体と首の周囲を囲う。マス数＝未確認。

出典：https://ark.fandom.com/wiki/Quetzal、https://ark.fandom.com/wiki/Chain_Bola

3. 手順

A プラットフォーム檻

  1. テイム済みケツァルコアトルスのプラットフォームサドル上に、ドア枠と天井で檻を組む。
  2. 各開口部を点検する。幅 >1 マスかつ高さ >1 マスの穴を作らないこと。
  3. 野生個体のところへ飛び、檻の中に収める位置取りをする。
  4. すぐに降りる。降りた瞬間、自分のケツァルコアトルスは停止する。
  5. 野生個体は壁をすり抜けられなくなり、閉じ込められる。
  6. 檻の外側を回り込み、隙間やドア枠越しに、檻の外に出ている頭部へ正確な射撃を数発当てる。
  7. 昏睡するとプラットフォームサドルの上に倒れる。ここで自分のケツァルコアトルスを動かさないこと。 動かすと野生個体がプラットフォームを貫通して落下する。出典は地上のほうが遥かに危険だと述べる。

B チェインボーラ

  1. バリスタタレットを設置する（地上、または自分のケツァルコアトルスのプラットフォーム上）。
  2. チェインボーラを命中させ、対象を地上に落として約 15 秒拘束する。
  3. 拘束中に麻酔矢／麻酔ダートを撃ち込む。
  4. 動き出したら再度チェインボーラを撃ち、昏睡まで繰り返す。

自分のケツァルコアトルスに載せたバリスタなら逃げる野生個体を追える。 地上設置の場合は、最初に当てられ、かつ逃げた先もカバーできる位置を事前に計算しておく必要がある。

C 冷凍落下

  1. スタミナの高い雪フクロウで対象の真上やや前方に位置取る。
  2. 右クリックの冷凍能力で自ら衝突し、2 体とも凍った状態で落下する（凍結中は落下ダメージを受けない）。
  3. 冷凍を維持したまま、ケツァルコアトルスの本体と首の周囲に標準の恐竜用ゲートの枠を三角形に置いて囲う。
  4. 麻酔を撃ち始める。

着地前に跳んで飛び直さないと、自分の雪フクロウが落下ダメージを受けて死ぬことがある。 枠で囲わず、冷凍衝突を繰り返して低空を飛ばせ続ける運用も出典は挙げている。

出典：https://ark.fandom.com/wiki/Quetzal（Quetzal Cage Strategy／Chain Bolas／Snow Owl Strategy）

4. 誘導方法

  • 野生のケツァルコアトルスは反撃せず、攻撃されると逃げるだけ。したがって「敵対させて追わせる」誘導は存在せず、追跡のみ。
  • 50/50 現象：驚いた個体はマップ座標 50,50 へ向かい、その周辺を徘徊する。出典は既知のバグとして扱い、 2 点を注意する。The Island の 50,50 一帯は大型肉食生物が密集（ティラノサウルス、スピノサウルス、テラーバード、プルロヴィアなど）。 Ragnarok の 50,50 は山岳地帯で、逃走中に岩の斜面に引っかかりやすい。引っかかれば撃ちやすいが、 昏睡すると斜面を大きく滑り落ち、その下に捕食者がいることがある。
  • 追跡用の騎乗生物（出典の推奨）：タペヤラ（前席から操作しつつ射撃可）、グリフィン（飛びながら撃て、速度も足りる）、 ワイバーン（追従設定にして背に立って射撃可。速度は勝るが旋回半径が大きく照準が難しい）、 アルゲンタヴィス＋グラップリングフック＋パラシュートのソロ法。

出典：https://ark.fandom.com/wiki/Quetzal

5. 閉じるタイミング

  • A 方式：野生個体を檻の位置に収めた直後に降りる。降りた瞬間に自分の騎乗生物が停止し、檻が固定される。 この動作が「扉を閉じる」に相当する。
  • B 方式：扉は無い。時間枠＝チェインボーラの約 15 秒。
  • C 方式：冷凍を維持している間に枠を置き、解凍前に囲みを完成させる。

出典：https://ark.fandom.com/wiki/Quetzal、https://ark.fandom.com/wiki/Chain_Bola

6. 麻酔を撃つ位置

  • 頭部。ケツァルコアトルスの弱点はトサカ（crest／hair）で、当たればヘッドショット扱い。 最も効率が良いが最も当てにくい部位。
  • A 方式の実務：頭は檻の外に出ていることが多いので、外側から頭へ正確に数発当てる。
  • 武器：出典はロングネックライフル＋強力な麻酔ダートを、空から落とす最良の手段として名指ししている。
  • 水面の上空で昏睡させないこと。溺死する。

出典：https://ark.fandom.com/wiki/Quetzal（Weakness／Weaponry／KO Strategies）

7. よくある失敗

  • 檻の開口が大きすぎる：2×2 の穴は抜けられる可能性がある。幅か高さのどちらかを 1 マス以内に保つこと。
  • 昏睡後に自分の騎乗生物を動かす：野生個体がプラットフォームから落ちる。
  • 水上で昏睡させる：溺死する。
  • 50/50 現象で危険地帯へ流される：4 節参照。
  • レアフラワーは無効：出典はケツァルコアトルスにレアフラワーが効かないと明記。誘引用に使わないこと。
  • 昏睡後に小型肉食生物に食われる：出典は「ディロフォサウルスの小さな群れでもケツァルコアトルスのテイムを台無しにできる」と記す。
  • 空中スタミナの問題：256 以降、ケツァルコアトルスは空中でスタミナが回復しない。出典が挙げる ?AllowFlyingStaminaRecovery=true はサーバー／ソロ用のコマンドであり、トラップの技術ではなく設定の話。
  • プラットフォーム上のバリスタ：バニラ設定ではタレット類をプラットフォームサドルに建てられない （出典はティタノサウルスの節で言及）。B 方式の「自分のケツァルコアトルスに載せる」が現在も可能かは＝未確認。

出典：https://ark.fandom.com/wiki/Quetzal、https://ark.fandom.com/wiki/Taming、https://ark.fandom.com/wiki/Titanosaur

8. 対象生物

  • Quetzal／ケツァルコアトルス／風神翼龍 — 3 方式ともこれを主対象とする。
  • チェインボーラの拘束可リスト（fandom の "Creatures Affected"）は多数の中大型生物を含み、ケツァルコアトルスも入っている。 一方、神ゲー攻略の判定表ではケツァルコアトルスは「チェインボーラ △」＝拘束できるが誘導が難しい。
  • 神ゲー攻略で「チェインボーラ ◯」の生物一覧は bear-trap-and-bola_JP.md の 8 節にまとめてある。
  • C 方式で使う標準の恐竜用ゲートの枠は、通常はケツァルコアトルスを閉じ込められない （体格超過リストに入っている）。冷凍落下という特殊状態でのみ成立する点が本方式の前提。
