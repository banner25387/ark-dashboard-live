ファソラスクス（Fasolasuchus／法索拉鱷）テイム難関攻略

マップ：スコーチドアース、アベレーション、ラグナロク、アストレオス。テイム方法：特殊（グレネードでスタン→騎乗ミニゲームで岩にぶつける）。行動気質：攻撃的。kamigame の ASA PvE 評価は S。 （出典：data/生物清單.csv、data/馴服方式.csv、data/官方三語對照.csv、https://kamigame.jp/asa/page/276145365869139134.html）

1. なぜ難しいか

  • まず爆発物でスタンさせる必要がある：グレネードが至近距離で爆発するとスタンモードに移行し、掴めるようになる（設定上は爆発で背中のトゲを落とす流れ）。C4 やロケットランチャーでも可だが、いずれも敷居が高い（グレネードは Lv38 解放）。
  • その後は騎乗ミニゲーム：騎乗して岩にぶつけることで気絶値が溜まる一方、コントロールゲージは減り続け、0 になると騎乗解除される。
  • ぶつける対象を間違えると即中断：壊せないオブジェクトへの衝突、崖からの飛び降り、入水はコントロールゲージが残っていても強制的に騎乗解除となる。
  • 地中に潜っている：顔だけ出している場合も完全に潜っている場合もあり、近づきすぎると襲ってくる。探索自体に技術が要る。
  • 巨体（ドラッグウェイト 425）で攻撃的：失敗のコストは大型捕食者に至近距離で噛まれること。

（出典：https://kamigame.jp/asa/page/276145365869139134.html）

2. 生息地と見分け方

data/生物清單.csv ではラグナロクにも分布するが、kamigame の文字説明はスコーチドアース（外周の砂漠エリア全体、顔出しまたは地中）に限られており、ラグナロクの正確なホットスポットは未確認。 実務上は上空から望遠鏡で探し（至近距離に寄ると襲われる）、岩オブジェクトの多い場所を選んで仕掛ける——ミニゲームが岩への衝突を前提にしているため。 （出典：https://kamigame.jp/asa/page/276145365869139134.html、data/生物清單.csv）

3. 事前準備

アイテム用途
グレネード 15 個程度スタン用（Lv38 解放。材料：繊維 15／石 20／火薬 30／皮 5／金属のインゴット 2／原油 4）。C4 やロケットランチャーでも可
ギリー装備必須ではないが気付かれにくくなる（カマキリのテイムにも使える）
餌超級キブル（黄色）が最良、次いで羊肉・霜降り肉…（肉食の順）
昏睡アイテム気絶後に手動で与える。餌は自動で食べさせる（手動給餌はテイム効率を下げる）

（出典：https://kamigame.jp/asa/page/276145365869139134.html、data/馴服方式.csv）

4. 手順

  1. グレネードとギリー装備を用意し、岩の多い地形で対象を探す。
  2. 地中に潜っている個体へグレネードを投げ、至近距離で爆発させてスタンさせる。
  3. すぐに駆け寄って騎乗し、ミニゲームを開始する。
  4. 操作して岩にぶつける。コントロールゲージは減っていくが、衝突でゲージが回復し気絶値も増える。気絶値が最大になると昏睡する。
  5. 昏睡したら餌と昏睡アイテムをインベントリに入れ、餌は自動・麻酔は手動で管理してテイムゲージ 100% まで維持する。

気絶値の増加量（衝突したオブジェクト別、kamigame の検証値）：岩 5／骨・岩塩 50／水晶 50〜250（不確定）／黒曜石 250／金属鉱石・エレメント鉱石 400。 → 早く終わらせたいなら黒曜石や金属鉱石にぶつける。ただの岩が最も効率が悪い。 （出典：https://kamigame.jp/asa/page/276145365869139134.html）

5. 失敗時の対処

  • 強制的に騎乗解除された：壊せないオブジェクトへの衝突／崖からの落下／入水が原因。開始前に地形からこの 3 つを排除する。
  • コントロールゲージが 0 になった：これも振り落とされる。衝突自体がゲージを回復させるので、「走り回る」より「ぶつけ続ける」方が安全。
  • グレネードを外した：15 個程度用意するのは外す前提のため。
  • 気絶値が 0 に戻った：最初からやり直しになる。麻酔品は十分に持つ。
  • 餌を手動で与えた：テイム効率が下がる。自動で食べさせる。

（出典：https://kamigame.jp/asa/page/276145365869139134.html）

6. テイム後の用途

kamigame の ASA PvE 評価は S。サドルは Lv70／40 EP で解放され、ドラッグウェイト 425 の大型陸戦ユニット。 出典未確認の性能詳細は本ファイルでは書かない（該当ページの性能節は図表主体で、今回の抽出では取得できなかった）。詳細数値は未確認とする。 （出典：https://kamigame.jp/asa/page/276145365869139134.html）
