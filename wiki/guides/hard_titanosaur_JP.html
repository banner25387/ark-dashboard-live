ティタノサウルス Titanosaur（泰坦龍）テイム攻略

難易度テイム方法本カードが扱うマップ
極高気絶（ただし餌も麻酔薬も使わない。攻城兵器で頭を撃つ）The Island、Scorched Earth、The Center

出典：テイム方法は data/馴服方式.csv（出典＝fandom ヒューリスティック、信頼度「低（要検証）」——本カードで fandom 本文により特殊型の気絶テイムであることを確認）。 生息マップは data/生物清單.csv。攻略内容は https://ark.fandom.com/wiki/Titanosaur の要約・再構成で、引き写しではない。 繁体中文版 hard_titanosaur.md と節構成は一対一で対応。

1. なぜ難しいのか

  • テイム機構がそもそも違う：食料も麻酔薬も使わない。気絶させるには大型の投射兵器で頭部を撃つ必要があり、気絶後はインベントリを開いてサドルを置くと瞬時にテイムが完了する。
  • 公式サーバーでは「一時テイム」：サドルを置いた瞬間から 16〜20 時間のカウントダウンが始まり、その後餓死する。公式設定では給餌できない（非公式サーバーで ?AllowRaidDinoFeeding=true を有効にした場合を除く）。
  • 数の上限：公式サーバー（および多くの既定設定）では、The Island と Scorched Earth 上に同時に存在できるのは最大 3 体まで。
  • 兵器のハードルが高い：カタパルト／バリスタ／ロケットタレット／キャノンはいずれも序盤に用意できるものではなく、しかも頭部に当てる精度が要る。
  • 人手が要る：出典は「非常に難しく、部族員数名と、できればキャノンを積んだケツァルが必要」と明言している。

出典：https://ark.fandom.com/wiki/Titanosaur

2. 生息と見分け方

  • 本カード範囲の生息マップ：The Island、Scorched Earth、The Center（全体では Ragnarok、Crystal Isles、Lost Island、Fjordur も含む）。出典：data/生物清單.csv
  • 見分け方：ゲーム内最大級の陸生生物で、遠距離からでも見間違えようがない。
  • Tek 洞窟には入れない：大きすぎて「入場不可」リストに明記されている生物の一つ。出典：https://ark.fandom.com/wiki/Tek_Cave
  • 正確な湧き座標：出典に文章化された座標表がない。未確認。

3. 事前準備

各兵器の一撃あたりの気絶値（出典の表）：

兵器与える気絶値
カタパルトタレット Catapult Turret70
バリスタタレット Ballista Turret（出典の表は空欄）
ロケットタレット Rocket Turret400
キャノン Cannon1200
キャノンシェル Cannon Shell4800

兵器選択の注意：

  • バリスタのボルトは現状効かない疑いがある——出典には、これを使ってティタノサウルスをほぼ殺しかけた末にカタパルトへ切り替えたという記録がある。
  • ロケットタレットは極めて慎重に（火力が高く殺しやすい）。
  • 開発者 Jen の Twitter 上の発言は「キャノンかカタパルトの石弾を頭に当てるのが最も効率的」。

その他の必携品：

  • ティタノサウルスのサドル（Titanosaur Platform Saddle）——これが「餌」に相当し、気絶後にインベントリへ入れるとテイムが即完了する。
  • 人手：役割分担（誘導、砲の設置、照準）。
  • ケツァルのプラットフォームサドルにキャノンを積む案も検討に値する。

餌：公式サーバーでは不要。非公式で ?AllowRaidDinoFeeding=true を有効にすればベリー、作物、Kibble (Carbonemys Egg)、メジョベリーを与えられるが、飼い葉桶からも自分のインベントリからも自発的には食べず、必ず遠隔使用（remote use）で与える必要がある。シングルプレイでは ShooterGame\Saved\Config\WindowsNoEditor\GameUserSettings.ini の [ServerSettings] セクション末尾に AllowRaidDinoFeeding=true を追記する。

出典：https://ark.fandom.com/wiki/Titanosaur

4. テイム手順

  1. まず「一時テイム」でよいのか恒久的に欲しいのかを決める——公式設定では一時テイムで、サドルを置いた時点から 16〜20 時間のカウントダウンが始まる。恒久的に残すには非公式／シングルプレイで給餌設定を有効にする必要がある。
  2. 攻城兵器（第一候補はキャノンまたはカタパルトタレット）と十分な弾薬、そしてティタノサウルスのサドルを用意する。
  3. 目標を見つけ、頭部に安定して命中させられる位置に兵器を据える（地面の固定基礎、またはケツァルのプラットフォームサドル）。
  4. 頭を撃ち続けて気絶値を蓄積させる。気絶値を得ると特殊なモーション（出典の記述では「頭を振る」）を見せるので、頭に当たっている確認に使える。
  5. 気絶したらインベントリを開き、サドルを置く → 即テイム完了（何も与える必要はない）。
  6. 公式設定では、ここから 16〜20 時間のカウントダウンとの競走になる。

出典：https://ark.fandom.com/wiki/Titanosaur

5. 失敗時の対処

  • 殺してしまった：最も多い失敗。ロケットタレットとバリスタが特に危険で、バリスタは「気絶を与えず体力だけ削る」可能性すらある。カタパルトかキャノンに切り替える。
  • 頭に当たらない：胴体へのダメージでは気絶が溜まるとは限らない（同じ頭部限定機構を持つロックエレメンタルの項で出典はより明確に書いている）。高所に据える、砲座を固定する、複数人で照準を合わせる。
  • テイムしたのに餓死した：公式設定ではこれは想定挙動であり失敗ではない。残したいなら先に設定を変える。
  • マップに既に 3 体いる：上限に達していると新たに湧かない。出典は公式パッチノートの記述が 3 体だとしつつ、それ以上を見たという報告もあると注記しており、数値自体は要検証扱い。
  • サドルを持ってきていない：気絶させても何もできず、気絶値は自然に抜けていく。出発前に点検する。

出典：https://ark.fandom.com/wiki/Titanosaur

6. テイム後の用途

  • 移動要塞：ティタノサウルスのプラットフォームサドルが支えられる建築規模はゲーム内最高クラス。
  • 攻城／解体：体格と踏みつけのダメージにより、PvP の攻防や制圧で圧倒的な存在感を持つ。
  • 公式サーバーでの位置付けは「使い捨て」：16〜20 時間で餓死するため、常駐マウントではなく一回の作戦のための消耗兵器として扱われる。
  • 制限：大きすぎて Tek 洞窟に入れない。出典：https://ark.fandom.com/wiki/Tek_Cave
