メガケロン（Megachelon／島龜）テイム難関攻略

マップ：ジェネシス パート 1、ロストアイランド、フィヨルド、ジェネシス パート 2。テイム方法：特殊（バラキートの魚群をメガケロンに引き合わせる）。行動気質：中立的。kamigame の ASA PvE 評価は S。 （出典：data/生物清單.csv、data/馴服方式.csv、https://kamigame.jp/asa/page/437226477587554227.html）

1. なぜ難しいか

  • 餌をインベントリに入れる方式ではない：バラキートの魚群をメガケロンのそばへ誘導する必要があり、2 つの対象をそれぞれ探して誘導しなければならない。
  • 魚群が見つけにくい：小魚の集合体で規模も小さく、水中では視認性が低い。
  • テイム中に妨害が入る：サーモンやシーラカンスが魚群を襲い、魚群が食べ尽くされるとテイムが中断し、ゲージが徐々に減少する。
  • メガケロンが被弾するとゲージが 0 になる：減少ではなく 0。メガロドンやデンキウナギなどの脅威は先に排除しておく。
  • 全工程が水中：スキューバのタンクは複数用意する（ラザルスチャウダーでも可）。

（出典：https://kamigame.jp/asa/page/437226477587554227.html）

2. 生息地と見分け方

ジェネシス パート 1 の海洋（深海）バイオーム。背中に地形を乗せた巨大な海亀で、移動が非常に遅い。この遅さは利点でもあり、先にメガケロンを見つけてから周囲で魚群を探す方が効率的。 （出典：https://kamigame.jp/asa/page/437226477587554227.html）

3. 事前準備

アイテム用途
スキューバ装備（タンクは複数）全工程が水中。ラザルスチャウダーでも可
剣襲撃してくる魚（サーモン、シーラカンスなど）の撃退用
メディカルブリュー回復用。半スタックで十分
バシロサウルスなどの水中生物移動用。メガロドン等を撃退できる戦力が望ましい

装備の品質は原始的でも構わない。 （出典：https://kamigame.jp/asa/page/437226477587554227.html）

4. 手順

  1. 上記を用意し、周囲のメガロドンやデンキウナギなど敵対生物を排除する。
  2. メガケロンを見つけ、その周辺でバラキートの魚群を探す。
  3. サバイバー単身で誘導する。魚群は非常に遅く、少し離れれば敵対も切れる。逆にメガケロンを殴って魚群の方へ誘導してもよい。
  4. 両者が接すればテイムが進行する。この間、魚群を襲うサーモンやシーラカンスを撃退し続ける。
  5. テイムゲージ 100% で完了。

（出典：https://kamigame.jp/asa/page/437226477587554227.html）

5. 失敗時の対処

  • 魚群が食べ尽くされた：テイムが中断しゲージが減少する。亀を守るより魚群を守る方が優先。
  • メガケロンが被弾した：ゲージが 0 になる。開始前に周囲を掃除しておく。
  • 魚群が海面に上がって降りてこない：kamigame の実戦メモ。敵対中は浮上しない方がよい。
  • 魚群に殴られる：近づくと高頻度で固定 20 ダメージを受ける。密着して誘導しない。
  • 酸素が足りない：タンクを多めに持つか、ラザルスチャウダーに切り替える。

（出典：https://kamigame.jp/asa/page/437226477587554227.html）

6. テイム後の用途

  • 移動式の海上／水中プラットフォーム：背中に建築でき、水域探索や長時間作業の拠点になる。
  • 酸素供給：fandom のムーダー攻略では、スキューバの代わりにメガケロンで酸素を確保する手が挙げられている。さらに「メガケロンが酸素を供給し、ギガノトサウルスがボスを削る」という組み合わせも記載（ギガはムーダーのアリーナへ持ち込める）。
  • アストロセタスのテイム足場：fandom のアストロセタス記事は、TEK ホバースキッフの代替としてメガケロンを挙げている。速度は劣るが非常に硬く、月面バイオームの過酷な環境から乗員を守れるため、亀の背からキャノンで頭を狙える。

（出典：https://ark.fandom.com/wiki/Moeder,_Master_of_the_Ocean、https://ark.fandom.com/wiki/Astrocetus）
