パレオクトパス（Palaeoctopus／古章魚）テイム難関攻略

マップ：ジェネシス パート 1（ASA の新生物）。テイム方法：特殊（わざと掴まれ、口が開いた瞬間に麻酔アイテムを手渡す）。行動気質：逃走的。kamigame の ASA PvE 評価は S。 （出典：data/生物清單.csv、data/馴服方式.csv、data/官方三語對照.csv、https://kamigame.jp/asa/page/421238056842997029.html）

1. なぜ難しいか

  • テイムできるのは「壁に張り付いて擬態している個体」だけ：水中を泳いでいる個体は近づくと逃げてしまい、流れに入れない。
  • 肉眼ではまず見つからない：kamigame は「肉眼で探すのは非常に困難」とし、スキャナーなど位置を特定できる手段の用意を勧めている。
  • テイム＝わざと触手に掴まれること：掴まれている間は体力が徐々に減るので、メディカルブリューで支える必要がある。
  • 与えられるのは「口が開いた瞬間」だけ：口元へ運ばれ、嘴を数回鳴らした後に口が開く。そのタイミングで E キーによりショートカット 0 番の麻酔アイテムを渡す。
  • とにかく長い：バイオトキシンは 1 回 800、麻酔薬は 400 の気絶値だが、掴まれている間も気絶値は微減する。kamigame は高レベル個体では「数十分かかるのを覚悟」と明記している。
  • 全工程が水中かつ無防備：周囲のメガロドンやデンキウナギは先に排除しておく。

（出典：https://kamigame.jp/asa/page/421238056842997029.html）

2. 生息地と見分け方

ジェネシス パート 1 の海域。見分けの要点は「壁面に張り付いて擬態している」個体であること——泳いでいる個体は掴んでくれない。 kamigame の補足：一応陸に上がることもあり、陸で遭遇した場合はメガロドン等の排除が不要になる。ただし陸上個体は稀で移動が速く、誘導は難しい。 （出典：https://kamigame.jp/asa/page/421238056842997029.html）

3. 事前準備

アイテム用途
スキューバタンク水中呼吸用。予備を 2〜3 個
ラザルスチャウダー酸素消費を減らせる（必須ではない）
バイオトキシン気絶用の主力。対象レベル ÷3 個程度が目安（30〜40 個あれば十分）。麻酔薬でも可だが効率は半分。ショートカット 0 番に置く
メディカルブリュー回復用。10〜20 個
水中戦闘用ペット護衛用。バシロサウルスなどが推奨（クニダリアを倒して現地でバイオトキシンを集められる）

（出典：https://kamigame.jp/asa/page/421238056842997029.html）

4. 手順

  1. 上記を用意する（バイオトキシンはショートカット 0 番へ）。
  2. 壁に張り付いて擬態している個体を探す（肉眼では困難なのでスキャナー等を使う）。
  3. 先に周囲を掃討する：テイム中は完全に無防備になる。
  4. 近づくと擬態を解除して掴んでくる。掴まれている間は体力が減るので適宜メディカルブリューを飲む。
  5. 口元へ運ばれ、嘴を数回鳴らした後に口が開く——その瞬間に E で 0 番の麻酔アイテムを与える。
  6. 「口が開くのを待つ→与える」を昏睡まで繰り返す（バイオトキシン 800／麻酔薬 400、待機中は気絶値が微減）。
  7. 昏睡したら餌を入れる（最も効率が良いのは大トロ、次いで超級キブル、羊肉、霜降り肉）。100% でテイム完了。

（出典：https://kamigame.jp/asa/page/421238056842997029.html）

5. 失敗時の対処

  • 離脱したい：通常攻撃を連打すれば拘束から逃れられるが、相手は逃走し再度追跡する手間が生じる。必要がなければ抜けない。
  • 体力が保たない：メディカルブリューを 10〜20 個持ち、掴まれている間に飲み続ける。
  • 気絶値が溜まりきらない：バイオトキシン（麻酔薬の 2 倍効率）に切り替え、与えているのがショートカット 0 番のアイテムか確認する。
  • 対象が見つからない：水中を闇雲に泳がず位置特定手段を使う。陸に上がった個体を狙う手もある。
  • 他の海洋生物に妨害された：事前の掃討が不十分。

（出典：https://kamigame.jp/asa/page/421238056842997029.html）

6. テイム後の用途

kamigame の ASA PvE 評価は S、ドラッグウェイト 450。該当ページの性能節は図表主体で、今回はテキスト化されたスキル説明を取得できなかったため、詳細な性能は未確認とし推測では書かない。 （出典：https://kamigame.jp/asa/page/421238056842997029.html）
