難馴物種：Dreadnoughtus（無畏龍／ドレッドノータス）

本卡：E8-A5b｜寫成日 2026-09-13｜來源：ark.wiki.gg、data/馴服方式.csv（kamigame 本種頁）。名稱依 data/官方三語對照.csv。文字為本檔自行改寫。 出沒圖（依 data/生物清單.csv）：Extinction、Astraeos。第八屆社群生物投票的獲勝者。（來源：https://ark.wiki.gg/wiki/Dreadnoughtus）

1. 為何難

  • 馴服方式完全綁在 Extinction 的機制上：你不是餵牠也不是打昏牠，而是要把牠帶到 Element Vein（元素礦脈）前面，讓牠去吃，然後替牠擋五波腐化生物。（來源：https://ark.wiki.gg/wiki/Dreadnoughtus）
  • 礦脈等級決定馴服效率：最好找 Alpha 級礦脈，等級低的礦脈馴服效率會打折。（來源：同上）
  • 牠會對大型已馴生物產生敵意（進食階段除外），所以接近牠只能用小型坐騎（來源舉例 Thylacoleo）。（來源：同上）
  • 牠受的任何傷害都會影響馴服效率，而防守五波的過程中很難完全不讓牠挨打。（來源：同上）
  • 你的其他馴服生物不會主動攻擊那些腐化生物（連設成主動攻擊也一樣），所以單人時你必須有一隻夠強的坐騎自己扛。來源自己說不確定這是 bug 還是設計。（來源：同上）

2. 出沒與辨識

  • 巨大的蜥腳類，外觀帶有怪獸電影式的特徵。（來源：https://ark.wiki.gg/wiki/Dreadnoughtus）
  • 行動氣質：中立的（data/馴服方式.csv）。你不惹牠、也不騎大型生物靠近，牠就不會主動打你。
  • 判斷牠進入「可馴服狀態」的信號：牠開始吃礦脈時會發出一聲吼叫，脖子湧出能量。（來源：https://ark.wiki.gg/wiki/Dreadnoughtus）

3. 事前準備

  • 先勘查 Element Vein：
    • 盡量找 Alpha 難度的礦脈（等級低的礦脈會降低馴服效率）。
    • 技巧：如果附近只有已部署的 OSD／遠處的礦脈，可以去啟動它們然後立刻離開載入範圍讓事件中止，這樣才有機會刷出位置比較好的新礦脈。
    • 時機：最好避開剛結束的隕石雨，免得天氣事件變成額外威脅。 （來源：https://ark.wiki.gg/wiki/Dreadnoughtus）
  • Element：用來像和平馴服那樣餵牠，讓牠跟著你走1 分鐘。（來源：同上）
  • 小型坐騎：接近牠用（來源舉 Thylacoleo）。（來源：同上）
  • 一隻強力戰鬥坐騎：防守五波用。Carcharodontosaurus 是來源點名的首選。（來源：同上）
  • Cryopod：進食階段可以從 Cryopod 放大型戰鬥生物（因為那時牠不會對大型生物敵對）。如果伺服器不允許，就先把大型生物停在一段距離外，到時候用哨令叫過來。（來源：同上）
  • 清空路線上的可採集資源：牠跟著你走的時候很容易卡到樹。（來源：同上）
  • 不需要陷阱、不需要麻醉：data/馴服方式.csv 標「特殊」、餌欄是「-」。

4. 步驟

  1. 先找好一個 Element Vein（最好 Alpha 級）。
  2. 騎小型坐騎接近 Dreadnoughtus。
  3. 餵 Element → 牠會跟著你走 1 分鐘。把牠一路帶到礦脈。
  4. 牠走到礦脈前會開始吃，同時吼叫、脖子湧能量＝馴服流程啟動。
  5. 這時牠不再對大型生物敵對，把戰鬥坐騎放出來（Cryopod 或哨令叫來）。
  6. 防守五波腐化生物，牠們全部直接鎖定 Dreadnoughtus。敵人等級等同 Dreadnoughtus 的等級，種類取決於礦脈規模。
  7. 每一波結束牠會因為吃礦脈而增加馴服進度，每波上限 20%。
  8. 牠每咬一口會獲得／刷新一個「消化護盾」，會隨時間衰減。這個護盾是保護馴服效率的關鍵。但牠被攻擊時就不會吃，護盾也就不會刷新。
  9. 最後一波結束、牠吃夠了就完成馴服，所有相關的腐化生物會死亡／消失。
  10. 此時礦脈會轉為一般的 Element Vein 事件。要不要留下來打完由你決定；PvP 設定下建議先把 Dreadnoughtus 收進 Cryopod，因為牠的範圍攻擊會對礦脈事件造成大量誤傷。

（來源：https://ark.wiki.gg/wiki/Dreadnoughtus）

5. 失敗處理

  • 牠一直挨打、效率掉光：這是本種最核心的失敗模式。因為「被攻擊→不吃→護盾不刷新→更容易被打」會惡性循環，所以防守的重點是把仇恨吃下來，不是站在原地互毆。（來源：https://ark.wiki.gg/wiki/Dreadnoughtus）
  • 自己的馴服生物不動手：這是已知行為，不是你設定錯；單人時必須靠自己騎的那隻。（來源：同上）
  • 牠卡在樹上：帶路前先清掉路線上的可採集資源。（來源：同上）
  • 騎大型生物接近被打：換小型坐騎。（來源：同上）
  • 礦脈等級太低：馴服效率會下降，值得多花時間刷一個好位置的 Alpha 礦脈。（來源：同上）
  • 完成後被礦脈事件波及：牠的範圍攻擊會造成大量附帶傷害，PvP 設定下先收起來。（來源：同上）

6. 馴後用途

  • 打 King Titan 的最強解：ark.wiki.gg 在 King Titan 頁直接寫「一群突變滿近戰的 Dreadnoughtus 是最快最省事的方法，連 Alpha 難度也能在幾分鐘內解決，而且幾乎不掉血」。（來源：https://ark.wiki.gg/wiki/King_Titan）
  • 這一條就足以說明為什麼值得花這個工夫：牠是 Extinction 終盤的通關鑰匙之一。
