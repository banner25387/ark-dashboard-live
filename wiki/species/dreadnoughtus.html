馴服細節 / テイム詳細

  • 馴服方式：特殊；前置條件：需要現場有 Element Node（元素節點）才能開始；需準備 Element 若干；建議帶 Giganotosaurus／Carcharodontosaurus 等高輸出寵物打防衛戰；前提条件：近くにエレメントノードが出現していないとテイムを開始できない。エレメントを用意し、防衛戦用にギガノトサウルスやカルカロドントサウルスなど高火力のペットを準備する。；餌優先序：不吃餌；改為手渡し Element 誘導；步驟：1) 找到 Dreadnoughtus 與附近的 Element Node。2) 先清掉周圍的汚染生物。3) 把 Element 放快捷 0 格，靠近後手渡し（PC 按 E）。4) 手渡し後牠會跟隨你 1 分鐘，把牠帶到 Element Node（時間到再餵一次即可續）。5) 牠對 Node 吐出青白色吐息就是防衛戰開始的信號，守住牠。6) 撐過 5 波即完成。；手順：1) ドレッドノータスと近くのエレメントノードを探す。2) 周囲の汚染生物を掃討しておく。3) エレメントをショートカット0番にセットし、近づいて手渡しする（PCはEキー）。4) 手渡すと1分間追従するので、エレメントノードまで誘導する（切れたら再度手渡しする）。5) ノードに青白いブレスを吐いたら防衛戦開始の合図。守り抜く。6) 全5ウェーブを守り切ればテイム完了。；注意事項：牠會優先攻擊汚染生物，不先清場會拖慢誘導；防衛戰中牠被汚染生物打到會降低馴服效果，但沒受傷一段時間後牠會吃 Node 獲得約 10 秒護盾，護盾期間效果不降。防衛戰中我方對牠的攻擊無效化，可以放心用高輸出寵物掃場。kamigame 攻略班表示等級與防衛波數的關係未確認。；注意点：汚染生物を優先的に攻撃するため、掃討しないと誘導に手間がかかる。防衛戦中に汚染生物の攻撃を受けるとテイム効果が減少するが、しばらくダメージを受けないとノードを食べて10秒程度のシールドを得て、その間は効果が下がらない。防衛戦中はドレッドノータスへの味方の攻撃が無効化されるため、高火力のペットで守れる。攻略班はレベルと防衛難度の関係は不明としている。；推薦等級或裝備：鞍具 Lv100／100EP；Element 數個；Giganotosaurus／Carcharodontosaurus 等高輸出寵物；信心：高；來源：https://kamigame.jp/asa/page/282506437719021639.html

難度 / 難易度

  • 難度：極高；理由：要餵 Element 把牠帶到（最好 Alpha 級的）Element Vein 讓牠吃，再替牠防守五波腐化生物；牠受的任何傷害都扣馴服效率，而自己的其他馴服生物不會主動攻擊那些敵人，等於單人要靠一隻坐騎扛完全場。；理由（日）：エレメントを与えて（できればアルファ級の）エレメントベインまで誘導し、食べさせながら 5 波のコラプト生物から守り切る必要がある。本体が受けたダメージはすべてテイム効率に響き、しかも自分の他のテイム生物はそれらの敵を自発的に攻撃しないため、単独では騎乗生物 1 体で全てを受け持つことになる。；來源：https://ark.wiki.gg/wiki/Dreadnoughtus
