隱私權政策（PCL 直播工具）

最後更新：2026-09-06

「PCL 直播工具」是頻道主本人自行開發、僅供本人使用的個人工具，用途為管理自己的 YouTube 直播（建立直播、讀取自己頻道的影片清單）並在本機儀表板顯示遊戲進度。

  • 本工具只存取使用者本人授權的 YouTube 帳戶資料，且只在使用者自己的電腦上處理與儲存。
  • 本工具不會將任何 Google 使用者資料傳送給第三方、不用於廣告、不出售、不分享。
  • 授權憑證僅存放於使用者本機，使用者可隨時在 Google 帳戶安全性設定中撤銷存取權。
  • 本工具對 Google API 取得之資料的使用，遵守 Google API 服務使用者資料政策，包括「有限使用」規定。
